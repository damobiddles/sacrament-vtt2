# First playtest changes — 23 October 2026

Owner decisions implemented together:

- Healing descriptions allow yourself or any target within their existing range. Drinking an item heals its drinker. A dying hero cannot tend themselves.
- Healing spells cost 0 Horror; all other spells cost exactly 1, including Ultimate and random-book spells. Relic costs are unchanged. A natural 1 still adds its separate, general 1 Horror.
- The shared catalogue, sheets, public loot reference, GM loot results and designed loot show Horror amounts and public explanations. Private GM notes stay separate. Custom items can have their own public explanation.
- GM dice work without a hero: 1–20 d4/d6/d8/d10/d12/d20/d100 dice, shared with the table or GM only. Results are server-generated, saved in Activity and do not change HP.
- Push is available only after failed attacks. Ordinary stat checks and healing checks cannot Push. Selecting an enemy offers separate ordinary-check and unarmed-attack choices; item damage checks are attacks. Existing once-per-turn and no-repeat-push restrictions remain.
- Item attacks prompt for a target when none is selected. The target remains attached to the check and damage, including after reload. Looking at another card does not redirect damage. An unavailable target requires an explicit replacement.
- Successful healing and esoteric checks no longer offer damage controls. The server refuses to turn those checks into damage.

Healing amounts, effect resolution and once-per-rest tracking remain under GM control. These changes do not implement the earlier healing or scene-danger automation proposals. Existing heroes, IDs, saved data keys and table contents are preserved.

Validation includes regression tests which reproduced the prior behavior, separate GM/player browser tests for private dice and targeting/reload, catalogue cost checks, the complete release checks and required phone smoke check. Physical phones, Safari and sessions lasting hours are still unverified. Deployment/live verification is reported separately; this document alone is not a claim that a version is live.
