A tabletop roleplaying game

Sacrament RPG

A shared table for Sacrament RPG, in your browser. One person runs the game and everyone else joins from their own phone or computer, with no accounts and nothing to download.

Join a game Run a game Build and manage characters

Joining a game? You need a six-letter code or an invitation link from your GM. Running one? You get a code to share.

The Church keeps the world. Someone has to go where it won't.

Start in a minute

The GM makes a table and gets a six-letter code. Players type the code (or open the invitation link), pick a hero, and everyone is at the same table.

Made for phones too

Dice, hearts, turns and countdowns are handled for you, and the table stays on screen while you play. It works on a phone as well as a laptop.

The GM stays in control

Prepare the next scene in private, keep hidden cards and private notes hidden, and show things to the players only when you choose.
