Restore a heroes backup

Choose the JSON file you downloaded with the backup button. You can review it before restoring. Existing heroes are kept; a different version is added as a separate copy.

Earlier characters

Sacrament changed its rules: one Target Number a scene, Hearts, an Effort die, and gear in place of ability trees. Any character you made before that is still in this browser, exactly as you left it. Nothing here changes or deletes it. You can read it, download it as a file, and, when you choose, make a new hero from it. The new hero is a separate character; the old one stays.
