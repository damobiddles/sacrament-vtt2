Clear space

Leave room around the logo equal to the width of the rune’s stave. Nothing else sits inside it.

Smallest size

Horizontal logo: 120 px wide. Mark: 16 px, using the favicon version below 32 px.

Do

  • Use the dark version on near-black and the light version on light grey.
  • Keep the mark upright. The fork points up.
  • Use the one-colour mark when you can only print one ink.

Don’t

  • Recolour the rune, or swap the purple for another colour.
  • Stretch, rotate, outline or add shadows or glows.
  • Place the logo on a busy picture without a dark panel behind it.
  • Retype the wordmark in another font. Use the file.
Colour

Soot, parchment and candlelight

A dark ground, parchment-coloured text, oxblood accents and candle gold. Change a colour once in theme.css and the site follows. The values below are read live from the page. Contrast is measured against the page background: aim for 4.5 or more for body text, 3 or more for large headings.
